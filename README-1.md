# AI Job Market & Salary Analysis

## Overview
This project provides a comprehensive analysis of the global AI Job Market dataset. It explores key parameters such as salary distributions, impact of experience and education levels, demand for specific technical skills (Python, SQL, ML, Deep Learning, Cloud), industry-wise job availability, and remote work trends.

## Dataset
- **File Name:** `AI Job Market Dataset.csv`
- **Records:** 10,345 job postings
- **Features:** Job Title, Company Size, Industry, Country, Remote Type, Experience Level, Education Level, Technical Skills, Salary, Hiring Urgency, and Job Openings.

## Key Technologies Used
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn (Random Forest Regressor, Linear Regression)

## Setup & Execution
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Jupyter Notebook:
   ```bash
   jupyter notebook TayabaKhan_AI_Job_Market_Analysis.ipynb
   ```
